### 👋 About

I'm an **IT Support & Security Analyst at Log(N) Pacific**, working toward cloud security and identity engineering.

Day to day I harden Windows endpoints to DISA STIG baselines with PowerShell, run the full Tenable vulnerability lifecycle across 200+ assets, hunt in Microsoft Sentinel and Defender XDR with KQL, and write detection rules. Everything below is that same work done in the open, so you can read the reasoning and not just the result.

**How I document:** if a build broke, the README says so, including the bug I haven't fixed yet. A demo that looks finished but quietly doesn't work is worse than an honest one that says exactly where it's stuck.
